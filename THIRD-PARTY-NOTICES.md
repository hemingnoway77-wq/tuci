# Third-party notices

## ECDICT offline English-to-Chinese dictionary

Project and original dictionary source: https://github.com/skywind3000/ECDICT

License: MIT. TUCI ships a normalized, first-letter-sharded subset of the full
base CSV containing word, phonetic, Chinese translation and exchange fields.
`Assets/OfflineDictionary/dictionary.manifest.json` records the exact source
revision, original CSV hash and generation statistics; `LICENSE.MIT.txt` contains
the complete upstream notice and license. TUCI does not bundle the separately
licensed `lemma.en.txt` file. Dictionary part-of-speech labels and meanings are
preserved from the source translations rather than generated by a language model.

## Mozilla Firefox Translations / Bergamot offline English-to-Chinese translation

Project and source: https://github.com/mozilla/translations

TUCI ships the original Mozilla Release/base-memory English-to-Simplified-Chinese
model, the Bergamot WebAssembly engine, its source-form JavaScript loader, and
TUCI's local worker adapter. They run on-device with no model download or online
translation request. The engine uses the separately installed Microsoft Edge
WebView2 Runtime described below.

The complete MPL-2.0 license texts, original-file SHA-256 hashes, pinned model
download URLs, runtime version/revisions, source locations, and adapter source
are distributed alongside the application in `Assets/OfflineTranslation`:

- `LICENSE.MPL-2.0.txt` and `models.manifest.json` for the model.
- `LICENSE-MPL-2.0.txt`, `LICENSES-THIRD-PARTY.txt`, `runtime.manifest.json`, and
  `RUNTIME-SOURCES.md` for the inference runtime, adapters and bundled upstream
  components, including Marian, SentencePiece and intgemm.
- `index.html`, `runtime.js`, and `translation-worker.js` are TUCI modifications
  supplied in source form under MPL-2.0. Preserve these files and license/source
  notices when distributing the offline translation bundle.

The original model sources and license declaration are available at
https://github.com/mozilla/translations/tree/8eada038fd45bbf6fa58a412b22f80c79887fabc
and each exact original file is available from the URL recorded in its manifest.
No additional restrictions are imposed on the MPL-covered files by TUCI.
