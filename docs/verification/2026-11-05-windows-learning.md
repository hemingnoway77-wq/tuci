# Windows 应用内学习验收

日期：2026-11-05。基线：手机分支 `05d0e649068916630ceab74fa230f79f76fccb0b`，Windows 工作分支 `feature/windows-learning`。

## 完成行为

- 主窗口四个入口：收录、词库、漫游、每日阅读。新安装建立应用管理的本地词库；已有设置和 Markdown 位置继续沿用。
- 词库按目录浏览，搜索标题和正文，多选导入 Markdown 且不覆盖同名文件。普通中文笔记、词根和英文词条均可阅读；本地阅读不依赖 API 或 Obsidian。
- 单击内部链接显示简卡，双击直接打开全文。同名候选可选择，显式错误路径不回退到无关同名笔记。全文返回恢复滚动位置，包括从收录预览带入的位置。正文可以选择复制。
- 漫游沿用手机端权重公式，按本地日期计算记住／跳过次数；连续天数使用实际秒数。展示 ID 防止重复完成；切页、阅读全文、预览、主题变化及重绘不重复计数。状态原子保存，失败不推进当前卡片。
- 笔记索引与复习记录保存在词库之外且按库隔离，不改变同步 v1。复习进度目前各设备独立。
- 每日文章和正文中的 HTTP(S) 链接在应用内 WebView2 窗口打开，可返回、前进、重载和失败重试。Markdown 阅读仍为原生本地文档。

## 修复的边界

回归用例先观察失败再修复，覆盖重复词读取原文、元数据损坏后继续阅读、临时文件锁／目录权限失败保留学习身份、索引无法保存时保持会话身份、重命名后旧路径复用、重命名到旧目标路径、嵌套旧词库链接、刷新不关闭相同内容简卡、同词全文导航、捕获预览返回偏移。隐藏的程序目录和 Markdown 文件不进入学习列表。
