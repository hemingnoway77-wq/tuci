# Obsidian 式词库工作区验收

日期：2026-11-05。工作分支：`feature/windows-learning`，前一版基线 `0edbfaf59d71c5fa837a5063cf033428aa6bf2c2`。

用户要求直接参照 Obsidian 对应词库功能、UI 与动效。实现保持 C# / WPF 与本地 Markdown，使用自写控件和图标几何；参照官方 Workspace、Tabs、File explorer、Search、Page preview 等文档，不提取安装包源码或品牌资源。实现范围及公共接口见对应设计和计划。

## 已实现

- 完整灰黑／浅灰工作区，左侧窄工具栏、真实文件与目录树、中央标签页、右侧大纲／反向链接／出链。词库进入完整内容区，其他兔词入口保留在工具栏。
- 标签独立阅读位置与前进／后退，关闭、重开、拖动排序、重启恢复；Markdown 源码编辑、自动保存、Ctrl+S、文内查找、冲突保稿与另存副本。关闭和换库前保存，失败时保留窗口和草稿。
- 单击链接直接导航，Ctrl+单击新标签，Ctrl+悬停不抢焦点预览；真实渲染标题携带层级与源码位置，大纲与阅读／编辑跳转使用同一套标题元信息。
- 文件树创建笔记／目录、定位／排序／折叠、导入、笔记右键重命名／移动／书签／复制路径／回收、回收恢复。操作验证路径、不覆盖同名目标，保留笔记身份，编辑前备份。
- 全文字段搜索、短语、AND／OR／排除、正则和超时提示；Ctrl+O 快速切换、Ctrl+P 命令面板及标签快捷键。后台搜索防抖；各面板焦点下均可使用工作区快捷键。
- 真实关系图，拖动节点、缩放／平移、筛选、局部关系、双击或 Enter 打开。显示上限 300 节点／1500 连线，局部反链扫描上限 3000 篇，界面显示限额。
- 侧栏拖动调宽与约 170ms 收放、约 140ms 标签淡入、约 130ms 树展开；遵循系统动画设置，不对正文做缩放。时长是项目实现选择，并非声称取得 Obsidian 的私有动效参数。

## 保护与修复

安全文件操作与原有 Capture／Sync 共用 `.vocabcollector.write.lock`。七种写操作在锁占用时等待，取消后文件、索引和回收记录不变；保存仍检查期望内容／身份，冲突不覆盖外部文档。

实际验收修复：书签刷新重复、仅改大小写重命名不执行、被动刷新强制展开目录、图谱页命令操作隐藏文档、空标签右栏残留、对话框底部按钮裁切、TextBox 模板重复内边距造成文字裁切，以及按字体猜测大纲导致引用标题错位。保持之前的临时锁文件／索引失败、手写内容、路径与复习身份保护。
