# 2026-11-07 强制账号登录与极简手机登录验收

Windows 发布版本为 1.3.0，手机 PWA 的 Service Worker 版本为 `1c15b016548e9e8e`。

## 账号与数据

- Windows 只有通过账号验证或已有账号有效离线会话才能创建主窗口。退出、服务端返回未授权或会话失效后返回登录窗口。旧游客或设备配对信息不能解锁主窗口。
- 新账号自动绑定自己的服务器词库和独立本机目录。词库 Markdown 与学习元数据使用不同目录，避免元数据被当作词卡或同步内容。已有账号的词库绑定保持兼容。
- 用户指定账号已建立。178 篇 Markdown 已导入私有词库，逐篇拉回比较 SHA-256，178 篇一致、零冲突。未将词库内容或凭据写入仓库和公开发布包。
- 原始 7z 已完整备份到仓库外的用户数据目录，另保存可见 Markdown 和两份 canvas。`.obsidian` 配置及插件保留于原压缩包，不执行，也不作为词卡上传。
- 导入前后均生成服务器一致数据库备份。最终只读检查：账号内 178 条变更、178 篇有效笔记，其他词库原 182 条变更保留，测试会话数量为零，SQLite 完整性检查 `ok`。

## 登录界面

- 手机登录页仅显示兔词标题、账号和密码横线输入框、文字登录动作；错误仅在失败时出现。网页正文、控制项、占位文字和代码样式统一采用衬线字体。
- 成功后先准备该账号的数据和主页面，再执行登录文字下沉、压成短线、横向展开、整张登录页上揭。未完成时主页面不可交互，避免短暂显示别的账号。
- 动画仅改变 transform 和 opacity；键盘收起后测量视口。取消、迟到响应、窗口切换和减少动态效果设置有独立处理。
- 修正全局输入框样式优先级导致的圆角边框覆盖；最终登录输入框规则为零圆角、透明背景和单条底线。
- 修复更新恢复页的内联脚本被现有 Nginx CSP 阻止的问题：改为独立同源脚本，恢复页及脚本绕过 Service Worker 静态缓存。

## 验证

- `scripts/verify.ps1`：1099 项测试通过，Release 零警告、零错误；实际 WPF 控件、启动、160 次快速切换、更新和随包离线模型检查通过。
- 最终网页单测 82/82 通过；另有 11 项 IndexedDB 检查及 Windows Core → 网页 cookie/IndexedDB → Windows Core 实际往返通过。
- 在隔离本机目录调用实际 DesktopSync，通过公网 HTTPS 登录并下载全部 178 篇笔记，逐篇核验内容、加载词库索引、退出锁定、重新启动仍锁定，全部通过。没有改变正在运行的旧客户端或其词库。
- 最终线上 54 个网页文件逐一下载，与本地构建 SHA-256 全部一致。首页、功能、指南、下载和同步健康接口均 HTTP 200，官网下载版本为 1.3.0。
- 线上更新清单 RSA-PSS 签名验证成功，ZIP SHA-256 为 `959ee92bd2467923ea93d33e1286ac7049a413e2403f46b52ddbd36a87efae76`，本地及公网包大小均为 144226581 字节。
- 独立只读审查：Windows ZIP 54 项及官网部署 ZIP 17 项与发布目录逐文件一致。合计 126 个公开文件与 178 篇私人笔记摘要无匹配；未发现 Obsidian 配置、私有缓存和导入目录、私人账号标识、私钥或常见 API Key 标记。
- Nginx 配置检查成功，Nginx、同步服务及备份 timer 均 active。同步服务仍仅监听 `127.0.0.1:18096`，本次未增加业务端口。
