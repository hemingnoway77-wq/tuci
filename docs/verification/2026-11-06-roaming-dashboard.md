## 缺陷根因与回归

闲置闪烁来自同步每分钟完成（即使没有内容变化）→主窗口请求刷新→600 ms 防抖扫描→`_loading` 导致 `CanAdvance=false`→按钮禁用样式 Opacity=0.4→扫描结束恢复。新实现将已有卡片的推进状态与扫描状态分开，只有实际推进期间禁用按钮；Core 事务门与曝光身份防重仍在。

先用 3 个失败回归确认不变词库刷新、防抖刷新、同内容文件触碰都会禁用按钮且 `roaming.json` 字节不变；修复后连同无刷新对照共 4 项通过。

界面验收中还修复了两个边界：按住拖出区域仍显示，以及 Application.Shutdown 销毁主题资源时焦点回调重新解析资源导致异常。焦点层改为构造时绑定主题，后续只改可见性；关闭程序的真实冒烟已通过。三栏小窗状态栏原可用宽度不足 168 px 活动格，现收紧内边距，最右一周逐格验证在滚动视口内。

完整测试首次运行另发现测试宿主的跨 STA 图标样式冲突：阅读页测试创建全局 Application 后，按住控件测试的临时窗口清空局部资源时会回退到另一个线程的 Window 图标。测试窗口显式设置本地 Style／Icon，保留全部行为断言；生产程序使用同一 UI 线程，无需为此改动应用。
