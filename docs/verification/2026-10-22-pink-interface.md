# 2026-10-22 粉色界面与阅读预览

## 设计与交互

依据用户配色参考改版现有 Windows 应用。只借鉴浅粉、奶油白、柔黄色及轻盈温暖的气质，没有使用参考图中的人物、星星、笑脸或光线图形。

- 主窗口：浅粉渐变背景，奶油白圆角卡片，左侧收录、右侧阅读。深梅紫正文和玫瑰色主要操作形成层级。
- 设置页：同一套输入框、按钮、字体和留白，分为“连接 AI”“安放词卡”两个区域。
- 原创图标：粉底、奶油纸页、淡黄折角、玫瑰书签和几何字母 a。ICO 包含 16、24、32、48、64、128、256 七个尺寸；窗口和 exe 都使用此图标。矢量源稿、PNG 及重建脚本一起保留。
- 预览：原生可选择的 WPF 文档，展示标题、强调、引用、上下排列的释义、嵌套列表、词条和词根链接，隐藏 YAML 属性、Markdown 格式符号和程序注释。真正的代码内容仍作为代码展示，不混同于格式语法。
- 滚动条：闲置隐藏，滚动、拖动或移至滚动条区域时显示，停止滚动约一秒隐藏。透明时保留命中区域，拖动期间保持可见，不切换布局宽度。
- 窗口维持可调整大小，最小 900×640；较小窗口可滚动查看输入内容，主要操作固定在输入卡片底部。

主色：背景 `#FFE3ED` 至 `#FFF3F2`、纸面 `#FFFCF9`、正文 `#49333F`、按钮 `#BD416D`、柔黄色 `#FFF5D9`。不增加字体安装要求。

## 实现边界

Markdown 仅在显示层使用 Markdig 1.4.2 解析，再生成原生 FlowDocument；不需要浏览器或 WebView 运行环境，不运行 HTML、不读取远程图片。普通 HTTP/HTTPS 链接只有用户点击时才交给默认浏览器；本地词条链接验证为词库内已存在的 Markdown 后才交给 Obsidian。路径跳转、可执行文件、file: 等目标不能从词卡打开。

单词解析、HTTP 本地模型支持、DeepSeek 快速模式、模板、保存和本地补链继续复用已有实现。显示层不修改磁盘 Markdown，也不额外调用模型。Markdig 的 BSD-2-Clause 声明嵌入程序并随发布目录提供，见 `THIRD-PARTY-NOTICES.md`。
