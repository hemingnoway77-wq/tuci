# Obsidian 式词库工作区

用户明确要求直接照 Obsidian 的对应词库功能、UI 与动效实现，已选择参照对象并要求直接执行，跳过方案／确认问答。保留 WPF、本地 Markdown 与既有权重漫游，重做词库工作区。

## 对应行为

- Obsidian 默认深色工作区：窄左工具栏、紧凑文件树／搜索、中央标签与文档、可折叠右栏；无纸页大卡片与重复标题。中性灰、紫色强调、系统 UI 字体、1 px 分隔线、约 28 px 树行与 36 px 标签栏，正文 16 DIP／舒适行宽。支持明暗切换。
- 文件树真正包含文件和目录，展开／折叠、当前文件定位、排序、右键操作；新建笔记／目录、重命名／移动、可恢复删除和恢复；操作均在词库内安全执行。
- 中央多标签可切换、关闭、重开、拖动排序；每个标签有自己的文档和阅读位置。阅读／Markdown 源码编辑切换、自动保存与 Ctrl+S。保存前检测外部变更，冲突保留编辑内容且可另存副本，不覆盖外部内容。Ctrl+F 文内查找。
- 正文链接单击直接导航；Ctrl+单击在新标签打开；Ctrl+悬停显示浮动预览。新增词库以此覆盖此前单击简卡／双击跳转的约定。保留关联歧义选择、路径安全、返回位置，增加前进。
- 右栏大纲、出链、反向链接跟随当前文档；点击条目跳转。Ctrl+O 快速切换；Ctrl+P 命令面板；Ctrl+Shift+F 全库搜索；Ctrl+T/W/Tab/Shift+T 多标签快捷键。
- 侧栏可拖动调宽与折叠，折叠／标签切换／悬浮反馈使用克制的约 120–180 ms 缓动；遵循系统关闭动画设置。具体时长是本项目实现选择，非声称取得 Obsidian 私有动效参数。
- 词库占用完整内容区，主窗口其他入口可从左工具栏返回。现有收录、漫游、每日阅读、同步和 API 配置仍可使用。

## 数据约束

继续读取真实 Markdown 文件，保留手写段落。编辑使用原子替换与修改前备份；外部变更冲突不能丢编辑内容。新建不覆盖；移动／重命名不越界、不跟随链接；删除仅移动到本机可恢复回收区。索引 ID 与学习状态保持关联。不得用用户真实笔记做测试或自动迁移。

本次对应词库工作流；插件市场、Obsidian Sync/Publish、Canvas/Bases 等独立产品系统不作为词库面板的一部分。实现自行编写，不抽取 Obsidian 安装包源代码或品牌资源。

依据：[Workspace](https://obsidian.md/help/workspace)、[Tabs](https://obsidian.md/help/tabs)、[File explorer](https://obsidian.md/help/plugins/file-explorer)、Search、Backlinks、Outline、Page preview 官方文档。
