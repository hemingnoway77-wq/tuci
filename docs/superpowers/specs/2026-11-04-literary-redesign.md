# 书页界面与黑白主题

本次按用户确认的 C「书页」方向实施。保留全部收录、拼写纠正、Obsidian 链接与每日阅读行为，只重做表现层，并把每日阅读并入主窗口。

## 目标

- 去掉渐变背景、投影、胶囊标签和情绪化口号，改为纸页式排版：米色桌面、纸白卡片、1px 发丝线分区。
- 英文词条与文章标题使用衬线（Sitka / Georgia），中文标题与标签使用 Noto Serif SC，界面正文使用微软雅黑，音标、路径和日期使用等宽（Cascadia Mono）。
- 主题扩充为三套：**墨白**（无彩色）、**暖灰**（默认，纸页米色 + 酒红强调）、**玫红**（浅粉纸面 + 玫瑰强调）。
- 「每日阅读」从独立窗口改为主窗口内的第二个页面：顶部「收录 / 每日阅读」导航，首次进入懒加载；离开页面取消进行中的请求，返回后保留已加载文章。

## 结构

- `ThemePalette` 改为语义角色：Paper、Sheet、Ink、InkSecondary、InkTertiary、Line、LineSoft、Rule、Accent、AccentInk、AccentSoft、Margin、Error、Selection、Hover、ShellBackground。
- `ThemeManager` 默认暖灰，提供 `ThemeChanged` 事件，让标题栏的三枚主题色点与任何外部调色板变更保持同步；色点悬停显示主题名，选中项带细环。
- `Theme.xaml` 提供字体、卡片、按钮、输入框、页面导航、主题选项、路径列表、滚动条与提示样式。
- `MainWindow` 成为外壳：品牌章、页面导航、主题选择、刷新关联、设置与全局状态条；收录页保持原有输入/预览两栏。
- `ReadingPage` 取代 `DailyReadingWindow`，复用 `DailyReadingViewModel` 与 `IDailyReadingService`；文章列表与日期/配比侧栏在同一纸页页面内。
- 设置页改为左右两栏（连接 AI / 安放词卡），避免小窗口裁切字段。
- 窗口标题栏使用 Windows 11 DWM 的 caption/text/border 颜色，随主题切换为纸色底和墨色文字，不再沿用系统强调色；Windows 10 保持系统默认。
- exe 与窗口图标换成用户提供的单色兔子图形：黑底白色线描（两耳、圆环头、斜向把手），保留 16–256 像素多尺寸 ICO；界面左上角也使用同一图标。
- Markdown 预览改用语义色和衬线正文；四级标题上方加发丝线，五级标题弱化；加粗、链接和引用线使用主题强调色与柔色。

## 兼容与行为

- `appearance.json` 继续接受 `pink` / `warmNeutral`，新增 `mono`；缺失或损坏仍回退暖灰。
- 主题切换即时生效，不重建窗口、不清空输入、不重载文章、不调用 AI；设置页打开时同样即时更新。
- 每日阅读不新增模型请求，不读写 API 设置和词库；离开页面取消进行中的获取，缓存与离线行为不变。
- API Key 加密、笔记输出、词性归档、链接刷新与设置保存逻辑不变。

## 验证

- 单测：主题角色一致性、黑白中性、三套主题对比度、旧主题名兼容、持久化与写入失败回退。
- WPF 冒烟：三主题主界面/阅读页/设置页截图；页面切换与文章复用；刷新、取消、最小尺寸；切换主题不丢输入、不改写 `settings.json`。
- 完整 `scripts/verify.ps1` 与发布脚本。
