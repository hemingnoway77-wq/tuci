# 主题开关

本次按用户“保留粉色作为开关启用，新增克制主题，不用蓝色和绿色”的授权直接实施。

默认使用暖灰、米白、炭色及少量棕色的浅色主题；主窗口右上角提供“粉色主题”开关，打开恢复现有粉色，关闭使用暖灰。切换立即影响主窗口、已打开的每日阅读、设置页、笔记预览和滚动条，不重建窗口或清空输入，不调用 AI 或联网。

选择保存到 LocalAppData/VocabCollector/appearance.json，独立于 API/词库设置，因此未配置 API 也可切换并记忆。无偏好、坏配置或未知主题回退暖灰，保存失败保留当前视觉效果并提示。原 API 配置和 Obsidian 文件不改写。

沿用现有 WPF，不增加依赖。把硬编码配色改成动态资源，保持布局与字体；粉色调色板沿用原有颜色。暖灰调色板不含蓝/绿色相，图标的界面矢量也随主题变化；exe 品牌图标继续沿用现有资产。

验证重点：两套主题的主窗口/阅读/设置/预览实际截图；切换后既有控件实时更新；输入、笔记链接与文章仍可用；重启记忆、损坏回退、写入失败、最小尺寸；无额外模型请求。
