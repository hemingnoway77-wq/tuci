# Windows 应用内学习

依据：用户要求 Windows 对齐已实现的 iPhone 应用内学习，包含权重漫游、Markdown 阅读、词条简卡与跳转，不依赖启动 Obsidian。行为参考 `origin/feature/ios@05d0e64` 的 `docs/ios/requirements.md`、`ios/Sources/TuciCore/Roaming.swift` 和 `ios/App/LibraryViews.swift`。

## 实施选择

沿用 WPF 和现有 Markdown 文件、捕获与受管段落保护，在此基础上增加本地词库与学习服务。重写为另一套 UI 框架或先迁移到数据库都会增加数据迁移范围，当前不采用。工作区以手机分支为基线，保留已实现的配对同步，不修改 iOS/server 协议。

## 用户可见行为

- 收录、每日阅读、词库和漫游均有清晰的应用内入口。现有主题和已保存的 API 配置继续可用。
- 新安装无需选择 Obsidian 目录即可使用应用管理的本地词库；已有目录原样沿用，普通中文 Markdown 笔记和词根同样能浏览、搜索、阅读。阅读和复习不要求 API。
- 可导入 Markdown，重复目标不覆盖。捕获成功和命中已有词都能读取完整笔记。
- 正文单击内部链接只显示简卡，双击直接打开全文且不闪简卡；同名目标选择、缺失提示、显式路径不误配。返回恢复原文阅读位置，普通文本可选择复制。
- 漫游候选是英文词条，词根和普通说明排除。权重与手机一致：
  `0.5 + 3*ln(1+间隔天数) + exp(-入库天数/3) + 2*(1-(记住次数+1)/(记住次数+跳过次数+2)) + min(跳过次数,3)/3`。
- 天数取连续秒数/86400，当日次数按本地日期。记住后仍可再次抽中；不强行去重。一张实际展示生成一次 exposure，下一张/记住只能完成一次；预览、重绘、返回不计次数，跨日保留最后出现和入库时间。
- 复习状态原子落盘，写失败不推进当前卡。记录按词库隔离且不写入正文、不上传同步。稳定本地 ID 应能识别唯一内容未变的重命名，避免仅依赖绝对路径。
- 每日来源文章在应用内浏览，与 Markdown 阅读分离，保留 HTTP(S) 校验和失败提示。

## 数据与验证约束

旧目录不搬迁、不删除；原文、未知段落和人工编辑保护保留。目录扫描与链接解析不能穿越词库或跟随目录链接。导入不能覆盖已有目标。

核心测试覆盖元信息、普通 MD、路径、歧义链接、入库日期、权重/跨日/重复完成/持久化失败。真实 WPF 冒烟覆盖无 Obsidian 的词库搜索、阅读、简卡/跳转/返回、漫游、默认词库、重复词读取和最小窗口。已有收录、主题、缓存、同步 round-trip 继续验证。交付可运行的 Windows 打包版本及截图。
