# 每日阅读：轻量入口

用户已接受每日阅读入口，并明确缩小范围：每天获取英文文章，不匹配本地词库，不额外消耗 AI token。本规格按本次授权直接实施，沿用现有 WPF、粉色主题和单文件 exe。

## 范围与选择

选择官方公开 RSS/Atom + 本地每日缓存，不采用 AI 生成文章或爬取全文。每次推荐最多两篇通用泛读、一篇技术阅读；通用文章不冒充考研真题。卡片展示英文标题、纯文本摘要、来源与日期，点击用默认浏览器阅读原文。

阅读窗口从主窗口右上角打开，独立于 API 设置和单词整理任务。首次打开或跨日获取订阅源，同日重开使用缓存；手动刷新允许重新获取。跨日尽量轮换已有内容。网络失败保留缓存并提示，无缓存时提供清楚的重试入口。关闭阅读窗口取消正在进行的请求。

阅读组件不接触单词库、模型客户端、API Key 或单词链接维护流程，不请求 AI，不写入 Obsidian。缓存仅放入当前用户 LocalAppData/VocabCollector/reading。保留现有输入、笔记预览和整理速度。

## 数据边界

RSS/Atom 是不可信数据：禁用 DTD/实体解析，限制响应大小和时间，摘要转纯文本，仅接受 HTTP/HTTPS 原文链接。多个源并行，单源故障不阻塞其余结果；缓存损坏或无写权限不导致崩溃。

## 验收

覆盖 RSS/Atom、同日缓存、跨日轮换、部分失败、离线缓存、取消、损坏缓存、摘要清理和链接协议。真实 WPF 控件验证未配置 API 也可打开阅读、刷新、打开原文、关闭取消、最低窗口尺寸及零模型请求。完成全套既有验证，提供新的 Windows x64 单文件 exe。
