# 漫游回想与状态面板 Implementation Plan

> **For agentic workers:** 使用 subagent-driven-development 分工实施，已有隔离 Windows worktree；按测试、实现、独立审查与真实界面验收推进。

**Goal:** 在现有漫游页加入按住揭示释义、可关闭的第三栏阅读，以及权重／周月覆盖／每日活动状态，并修复闲置按钮闪烁。

**Architecture:** 保留 C#/.NET 10 WPF 与原生 Markdown 阅读。Core 在同一原子曝光事务记录每日词 ID／次数，统计按本地自然周／自然月；Desktop 用独立按住控件与现有 NoteReader，右侧第三栏在小窗自动收紧列宽。后台扫描不再切换推进按钮状态。

**Tech Stack:** C# / .NET 10 / WPF / existing Markdig；无新增依赖。

**Spec:** 本轮用户截图与 3 项漫游要求，沿用前文直接实施授权；周／月覆盖去重，日方格同时给出次数和不同词数。旧学习记录缺历史，不从 LastShown 伪造完整历史。权重条按抽取时权重相对本轮最高值显示，不显示数值。

## 任务与接口

- [x] Core：RoamingSession 与新增 RoamingStatistics，写失败不推进／不计活动，重复完成与恢复不重复计数；旧 JSON 兼容、损坏数据保留。覆盖按当前词库的英文词 ID 去重，周一为周起点；日活动保留 400 天，展示周一对齐的最近 12 周。RoamingExposure 可选 WeightLevel 固定抽取归一值。
- [x] HoldToReveal：Text/CanReveal/只读 IsRevealed/Hide；实际 Blur，鼠标／Space 按住显露，松开、失活、离页、换卡重新隐藏，非选择文字，空态清晰。
- [x] LearningPage：第二栏替换为状态模块，周月按钮、权重条与灰度活动格；第三栏 NoteReader 展开／关闭、内部跳转和后退，不切导航、不重抽／不计完成；下一张更新开启中的预览。最小 920×700 可用。
- [x] 闪烁根因回归：用隔离目录证明定时同步→扫描→CanAdvance false/true；改为只有真实推进才禁用两按钮，保留扫描及数据一致性。
- [x] 真实 WPF 冒烟：按住／松开／离页、第三栏与独立关闭、统计切换／提示、三主题／最小窗、零 API 和原笔记不变；完整回归840/840、文档、发布与交付哈希。

## 审查重点

1. 失去鼠标捕获或窗口失活时不能残留清晰答案。
2. 正文预览／导航不算一次新的漫游，恢复当前卡也不增加覆盖或方格次数。
3. 同词多次曝光只加日次数，不重复增加周／月覆盖，删词后分母与分子一致。
4. 午夜、跨周跨月、空词库和旧记录不能除零或制造虚假历史。
5. 后台扫描期间按钮不闪；实际推进仍阻止双击重复写，第三栏打开时小窗和按钮均可达。
