# 词库两栏阅读与客户端统一

用户明确收窄范围：需要 Obsidian 式文件列表、右侧 Markdown 展示及这两部分动效；颜色、字体与顶部导航遵循兔词当前风格。沿用已有 WPF／Markdown／Core，不增加依赖，不访问或改写用户真实词库。

## 实现选择

新增轻量 `LibraryBrowser` 作为词库唯一可见内容，左侧文件目录共用一棵树，搜索／导入／刷新；右侧单文档 `NoteReader`、路径及前进后退。树展开、文件选中与切文提供短促动效，不缩放正文，遵循系统动画设置。侧栏可调宽／收起。所有资源使用客户端现有 Paper/Sheet/Ink/Accent/Line/Hover/Selection，不注入黑色专属调色板。

主窗口所有页面保持同一个顶部导航、主题按钮与状态栏。旧完整工作区的标签／编辑器／图谱／右栏及其局部主题没有词库 UI 入口；既有 Markdown、学习状态及历史元数据保留，旧底层安全服务和独立测试仍可用。
