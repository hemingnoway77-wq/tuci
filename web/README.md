# 兔词网页版

在 iPhone 的 Safari 打开部署后的 `/tuci/`，点「共享 → 添加到主屏幕」，开启「作为网页 App 打开」。使用已开通的账号登录，其他设备登录同一账号即可继续使用同一词库。网页只提供登录，账号可由管理员或 Windows 端建立。用户名支持 2–40 个字符，密码为 8–128 个字符。原配对词库关联账号后，网页登录该账号会迁移原笔记与学习记录；迁移后原本地数据库与旧复习记录仍会保留。

账号会同步 Markdown 笔记、漫游事件与活动、阅读位置和纸页主题。笔记与待上传操作保存在账号独立的 IndexedDB 中。离线可继续使用已经登录的账号，联网时自动同步；退出后离线数据保留，再次读取需要重新登录同一账号。Safari 与添加到主屏幕的网页 App 可能有各自的存储，需要分别登录。AI 地址、模型与 API Key 只保存在当前设备，不进入兔词云端状态请求；生成词卡时浏览器会直接向用户配置的服务商发送单词和原句。

登录页固定墨白配色，以 Logo 印记、细线和纸页线稿丰富视觉，保留标题、账号/密码横线输入和文字登录。新账号的默认主题为墨白，已有账号的主题选择仍从本机与云端读取。鉴权与本机词库准备成功后，登录文字依次下沉、收线、拉伸，再随整页遮罩上移揭开主页面。减少动画设置与离线恢复直接进入；失败或换号会取消旧流程。

浏览器登录使用 HttpOnly、Secure、SameSite=Strict Cookie。应用不保存新账号的 Bearer token。自动同步携带预期词库标识，服务端与认证身份核对；另一标签切换账号时，当前标签会锁定，避免发送错误账号的待上传操作。离线启动需要先联网打开一次，AI 与新文章需要网络。

## 阅读点词

轻点正文中的英文单词，会高亮该次出现，并在附近显示「收录」「翻译」。收录会带上所在原句打开底部临时面板，保存后向下退出并保持原文位置；翻译只用于临时查看，不保存词条、不修改收录草稿。点空白、关闭、切换单词或离开文章会收起选项并停止查询/播放。文末使用来源行和单色 SVG 图标打开原文。

## 漫游与字体

漫游词卡使用一屏布局，标题右侧同时展示本周和本月覆盖，抽取倾向缩为词卡右上细条，每日漫游热图通过日历按钮打开弹窗。按住墨迹释义可查看，松手遮住；阅读整篇笔记时恢复正常页面滚动。

中文和英文统一使用自托管 Noto Serif SC 衬线字体，许可证和来源见 `fonts/OFL.txt`、`fonts/NOTICE.txt`。按 unicode-range 分片覆盖上游官方 SC Web 字符集，包含动态词库常用中文。6 个核心字形分片随离线壳校验缓存，其余分片只在用到时从本站获取、校验 SHA-256 并缓存；不会向字体 CDN 发送个人笔记。极罕见且不在上游字符集中的字使用后续本机衬线字体回退。

查词优先使用与 Windows 同源的 ECDICT 英汉词典（约 40 万条目，MIT 许可）。词条保留原始释义、词性、音标与词形原形。仅在需要时，从本站下载对应首字母分片；校验长度和 SHA-256 后保存在公开词典缓存中。内存最多保留两片，并分批解析以减轻手机负担。缓存不记录查询词、账号笔记或 API Key。

在「设置 → 离线查词」可下载完整词典，约 27 MB。支持显示进度、暂停和继续；失败时已成功校验保存的分片会保留。默认打开网页不会下载全部分片。Safari 与主屏幕网页可能各自存储，需要分别完成下载；清理网站数据或浏览器清理缓存后需重新下载。

未命中、缺少释义或本机暂不能取得对应分片时，保留 [MyMemory](https://mymemory.translated.net/doc/usagelimits.php) 联网参考译文回退，无需配置 Key，仅发送所选单词。离线词典命中时无需调用外部翻译或发音服务，音标来自词典、播放使用设备英文系统朗读。联网回退时可由 [Free Dictionary API](https://dictionaryapi.dev/) 补充音标和音频；缺失或失败时使用系统朗读。音频由用户点击播放，不会自动播放。外部成功查询仍只在当前页面内存中作最多 128 条缓存，不写入笔记或个人学习状态。

手机与 Windows 的离线能力有一项明确差异：Windows 完整包同时带有离线词典和翻译模型；手机网页可缓存同一词典，但未包含 Bergamot 翻译模型，词典未覆盖的词需要联网回退。AI 词卡在两个平台均需要用户自己的服务设置和网络。

## 运行和部署

从仓库根目录运行 `python3 web/build.py`，静态成品生成在 `.artifacts/web/`。部署时使用全新的输出目录，把成品目录整体挂到 HTTPS 站点的 `/tuci/`。同源的 `/tuci-sync/` 指向本仓库的同步服务。阅读接口由服务端读取限定来源的订阅和正文，AI 请求由浏览器直接发往用户设置的 HTTPS 地址，服务商需要允许跨域请求。

Service Worker 按文件摘要预缓存界面、主屏幕图标、词典小清单和 MIT 许可证；26 个 JSONL 分片仅随静态成品部署，不进入默认预缓存。词典 Cache API 与账号 IndexedDB 相互独立，缓存名称含完整词典清单摘要。源码变更后重新构建，整套发布文件一次切换。新版本完整下载并通过校验后即可接替旧缓存，刷新或下次打开页面时显示新版；正在编辑的页面不会被强制刷新。私人笔记、API 请求和设备凭证均不进入这个资源缓存。

如果 Safari 里的旧版一直没有更新，请先保存当前页未完成的编辑，再联网打开同一站点的 `/tuci/update.html`，完成后会自动回到兔词。此入口会检查并等待新版缓存启用，不会清理词库、设置或其他标签页的输入内容。离线或下载失败时保留现有版本，可以联网后重试。Safari 和添加到主屏幕的网页 App 有各自的存储与缓存；Safari 的更新入口只更新 Safari。主屏幕 App 联网打开时会下载新版，之后关闭并重新打开即可显示新版。

纯本地预览可用 `python3 -m http.server --bind 127.0.0.1 --directory .artifacts/web`。该方式可预览登录页面与静态排版；使用账号、同步和新闻需同时挂载同源后端。离线数据保存在当前浏览器，请在清理网站数据前先联网同步。

## 验证

运行 `node --test web/tests/*.test.mjs` 检查离线词典校验/取消/重试/真实词条、账号请求、阅读位置、收词、链接和复习逻辑。测试 fixture 包含在 `web/tests/fixtures/`，不依赖展开原生 iOS 目录。

账号 IndexedDB 检查：先运行 `npm install --prefix .artifacts/web-qa fake-indexeddb --no-audit --no-fund`，再运行 `node web/tests/storage-account-run.mjs`。可用 `FAKE_INDEXEDDB_MODULE` 指向其他安装的 ESM 入口。此检查覆盖账号隔离、离线改名、状态 FIFO、事件幂等、回收恢复和数据库重开，不连接用户服务器。网页运行和静态构建本身不需要 Node 依赖。

真实账号跨端往返：设置 `DOTNET` 为 .NET 10 SDK 可执行文件（必要时设置 `NUGET_PACKAGES`），运行 `node web/tests/account-roundtrip.mjs`。脚本在回环地址启动真实后端和临时 SQLite，以 Windows Core 建立笔记、复习与位置，再由 cookie 认证的网页存储编辑，最后由 Windows Core 验证。它使用 fake-indexeddb，不启动浏览器，不连接线上账号；成功后清理临时测试资料。`TUCI_KEEP_TEST_ARTIFACTS=1` 可保留隔离测试目录。

旧配对协议跨端检查：运行 `node web/tests/storage-run.mjs` 使用隔离数据库在浏览器、同步服务和 Windows 引擎之间传递笔记，测试所需的 Playwright 和 .NET 环境配置见该脚本开头。

手机交互还需在实际 Safari / 主屏幕入口检查：同账号登录、点词与系统朗读、按住揭示和松开隐藏、离线启动、下载暂停续传、换号后私有数据隔离。Node 检查不代替真实设备的触摸、系统声音与存储策略验证。
