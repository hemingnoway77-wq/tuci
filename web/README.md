# 兔词网页版

在 iPhone 的 Safari 打开部署后的 `/tuci/`，点「共享 → 添加到主屏幕」，开启「作为网页 App 打开」。建议第一次从主屏幕的兔词图标进入，再填写配对码和 AI 配置。浏览器存储与原生 App 的钥匙串各自独立。

已有词库的用户可以在原生兔词或 Windows 版先「立即同步」，再生成配对码。在网页版「设置 → 词库同步」输入该码。首次使用同步的设备可以使用管理员提供的激活码。笔记保存到浏览器的 IndexedDB，联网后与同一词库同步。漫游记录、阅读缓存和 AI 配置属于当前网页安装。离线启动需要先在联网时打开一次，AI 和拉取新文章需要网络。

## 阅读点词

轻点正文中的英文单词，会高亮该次出现，并在附近显示「收录」「翻译」。收录会带上所在原句进入收录页；翻译只用于临时查看，不保存词条、不修改收录草稿。点空白、关闭、切换单词或离开文章会收起选项并停止查询/播放。

临时中文译文来自 [MyMemory](https://mymemory.translated.net/doc/usagelimits.php)，无须配置 Key，匿名免费额度为每天 5,000 字符；仅发送所选单词。它提供参考译文，不是按文章语境生成的完整词卡。音标和词典音频由 [Free Dictionary API](https://dictionaryapi.dev/) 补充，缺失或音频失败时可以使用设备的英文系统朗读。免费公共接口的可用性和词汇覆盖有限，失败时可以重试或继续手动收录。读音由用户点击播放，不会自动播放。成功查询只在当前页面内存中作最多 128 条缓存，不写入离线资源缓存或个人笔记。

## 运行和部署

从仓库根目录运行 `python3 web/build.py`，静态成品生成在 `.artifacts/web/`。部署时使用全新的输出目录，把成品目录整体挂到 HTTPS 站点的 `/tuci/`。同源的 `/tuci-sync/` 指向本仓库的同步服务。阅读接口由服务端读取限定来源的订阅和正文，AI 请求由浏览器直接发往用户设置的 HTTPS 地址，服务商需要允许跨域请求。

Service Worker 按文件摘要预缓存界面和主屏幕图标。源码变更后重新构建，整套发布文件一次切换。新版本完整下载并通过校验后即可接替旧缓存，刷新或下次打开页面时显示新版；正在编辑的页面不会被强制刷新。私人笔记、API 请求和设备凭证均不进入这个资源缓存。

如果 Safari 里的旧版一直没有更新，请先保存当前页未完成的编辑，再联网打开同一站点的 `/tuci/update.html`，完成后会自动回到兔词。此入口会检查并等待新版缓存启用，不会清理词库、设置或其他标签页的输入内容。离线或下载失败时保留现有版本，可以联网后重试。Safari 和添加到主屏幕的网页 App 有各自的存储与缓存；Safari 的更新入口只更新 Safari。主屏幕 App 联网打开时会下载新版，之后关闭并重新打开即可显示新版。

纯本地预览可用 `python3 -m http.server --bind 127.0.0.1 --directory .artifacts/web`。该方式可使用本地笔记，联调同步或新闻需同时挂载服务。学习数据保存在当前浏览器，请在清理网站数据前先同步到自己的词库。

## 验证

运行 `node --test web/tests/*.test.mjs` 检查收词、链接和复习逻辑。运行 `node web/tests/storage-run.mjs` 使用隔离数据库在浏览器、同步服务和 Windows 引擎之间传递笔记，测试所需的 Playwright 和 .NET 环境配置见该脚本开头。

构建并按上面的本地预览方式启动服务后，运行 `node web/tests/reading-run.mjs chromium` 或 `node web/tests/reading-run.mjs webkit` 检查点词高亮、浮层、临时翻译、播放回退、异步请求竞态及收录原句。此检查使用隔离浏览器和模拟翻译响应，不访问真实词库、不消耗外部接口额度。需要已安装 Playwright 和对应浏览器；可通过 `PLAYWRIGHT_MODULE` 指定包路径。
