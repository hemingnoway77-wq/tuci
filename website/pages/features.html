THE WAY WE LEARN / 功能一览

遇见一个词，
留下一页自己的理解。

从阅读里的一个生词，到本地词库中的一篇笔记。兔词把收录、阅读和复习放在一起，让每次遇见都能接着往下读。

01 收录 02 词库 03 漫游 04 每日阅读

01 CAPTURE / 收录

把原句，
一起留住。

粘贴单词，也可以带上遇见它时的原句。连接自己的 AI 接口，点击「解析并保存」，一篇有语境的 Markdown 词卡就留在本地。

从用法出发
音标、释义、双语例句、常见搭配和句法模式，放在同一页里阅读。
保留遇见的现场
来源原句帮助理解当前语境，「我的笔记」留给自己的补充。
旧词直接打开
再次收录已有单词时读取原笔记，不重新调用模型，也不覆盖手写内容。

生成新词卡需要自行填写 API 地址、Key 和模型名；调用费用由所用服务商与模型决定。

02 LIBRARY / 词库

一页接一页，
读出词与词的联系。

左边是熟悉的文件目录，右边是安静的阅读区。搜索标题或正文，打开一篇笔记，再沿着已收录的关联词继续读。

关系就在正文里
悬停关联词查看简卡，单击进入全文。前进和后退会记住阅读位置。
已有词库继续用
导入 Markdown，或在设置中选择已有词库；使用 Obsidian 的笔记也能沿用。
文件始终属于你
一词一份普通 Markdown。兔词内就能阅读，无需安装或启动 Obsidian。
了解怎样安放已有笔记 ↗

03 ROAM / 漫游

先想一想，
再看答案。

让词库里的英文词条重新出现。释义先被柔和地遮住，给回想留一点时间；按住释义区域，答案才会显现。

有依据地再遇见
抽取会参考入库时间、距上次展示的间隔，以及记住和跳过的记录。
让这一轮轻一点
选择「下一张」或「今天已记住」，也能展开整篇笔记，回到词语的上下文。
看见自己的积累
查看最近的漫游活动，以及本周或本月遇见过的词库范围。

漫游无需 API。登录同一账号后，词库、记住与跳过记录、阅读位置和主题可在 Windows 与手机网页版之间同步；离线改动联网后继续合并。

04 DAILY READING / 每日阅读

从一篇文章，
走向下一个词。

打开来自公开订阅源的英文泛读和技术文章，在纯净正文里阅读。遇见生词，点一下就能翻译，也能连同原句送进收录面板。

读文章不消耗 AI 额度
文章获取、正文整理和缓存不调用模型。已缓存的正文可以离线继续阅读。
先查本地词典
安装包自带约 40 万条离线英汉词条；未命中时，再用自带的英译中模型在本机翻译。
收录不打断阅读
原句自动带入侧栏，确认「解析并保存」后才调用自己的 AI 接口，文章位置仍保留。

获取新文章需要联网。离线模型回退和可选的来源网页依赖 WebView2，Windows 11 通常已具备。

A QUIET PLACE / 给阅读留一点空白

同一本词库，
三种纸页心情。

墨白、暖灰、玫红，四个模块沿用同一套纸页排版。换一种主题，输入和阅读内容仍在原处。

Windows 词卡存成普通文件，阅读与复习可以从本地开始。手机打开网页版，登录同一账号，继续自己的词库与学习进度。
