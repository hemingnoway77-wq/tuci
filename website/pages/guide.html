01 OPEN / 解压并打开

给兔词一个完整的文件夹。

从下载页获取 Windows x64 发布 ZIP，先完整解压到一个普通本地文件夹，再双击其中的 兔词.exe。

请把 Assets 文件夹、兔词更新器.exe 和其他随附文件留在主程序旁边。不要只把一个 exe 单独移走，也不要直接在压缩包里运行。

完整解压后的文件夹

  • ↳ 兔词.exe双击打开
  • ↳ 兔词更新器.exe保留在原处
  • ↳ Assets /保留整个目录
  • ↳ 其他随附文件

发布包已包含 .NET、离线英汉词典和英译中模型，无需另装 .NET、Python、Node.js 或 Firefox。

02 KEEP / 安放本地词库

从空白开始，或接着原来的笔记。

首次打开先登录账号。兔词会为该账号建立独立的本机词库缓存，并下载云端笔记，无需安装或启动 Obsidian。

如果手边已有笔记，进入「词库」，点击导入 Markdown，选择一个或多个 .md 文件。兔词会复制文件，保留原文件，遇到目标同名文件也不会覆盖。

打开笔记后，右上方的删除会将笔记移入回收站；在文件列表下方点击回收站可选择恢复。删除与恢复会随账号同步，笔记内容保留在本机回收站中。

已有 Markdown 或 Obsidian 笔记可以导入当前账号，再同步到其他设备。一个单词保存为一份笔记；「按主要词性分文件夹」可以按需开启。Obsidian 插件和工作区配置不作为词卡同步。

已有版本保存过的词库位置会继续沿用。切换界面不会自动搬迁、删除或重排你的笔记。

03 CONNECT / 连接生成接口

准备生成新词卡时，再连接 AI。

点击右上角「设置」，填写服务商提供的三项信息，然后保存。兔词使用兼容 OpenAI Chat Completions 的接口，也支持符合该接口的本地模型服务。

API 地址
填写服务商的 API 前缀，例如 https://your-provider.example/v1。程序会追加 /chat/completions，也接受带此后缀的完整地址；不会自动补上 /v1。
API Key
填写服务商提供的 Key。Key 使用当前 Windows 用户加密保存在本机，不写入单词笔记。
模型名称
填写服务商实际提供的模型名。模型需要能根据提示返回 JSON 内容。

调用你配置的接口生成词卡，费用由服务商和所用模型决定。阅读笔记、导入 Markdown、漫游复习和获取每日阅读均不需要配置 API。

04 BEGIN / 收录第一个词

从一个真实遇见的单词开始。

  1. 打开「收录」，输入单词。

    可以粘贴遇见它时的英文原句，帮助生成更贴近语境的释义与用法。

  2. 点击「解析并保存」。

    完整内容通过校验后才会写入词库。生成过程中可以取消；遇到已有单词时，直接打开原笔记。

  3. 读完这一页，再去漫游。

    在「词库」阅读全文和关联词；在「漫游」先回想，再按住释义区域查看答案。选中释义区域后，也可以按住空格查看。

ANOTHER WAY IN / 也可以从阅读开始

打开「每日阅读」，在纯净文章正文中点选英文词，选择「翻译」或「收录」。收录侧栏会带入所在原句，确认「解析并保存」后才调用 AI，读到的位置会保留。

05 EVERYWHERE / 账号与手机

换一块屏幕，接着学。

Windows 与手机网页版均需先登录。每个账号拥有独立的云端词库；Windows 自动为账号建立本机缓存，已有账号绑定的词库目录会继续保留。随后在手机网页版登录同一账号即可接着学。

iPhone 用 Safari 打开网页版，点击分享按钮，选择「添加到主屏幕」，以后从桌面图标进入。Safari 与主屏幕入口可能使用独立存储，需要分别登录和填写 API 设置。

词卡和笔记、记住与跳过记录、漫游进度、阅读位置及主题会随账号同步。首次登录需要联网；缓存后的词库可离线使用，改动将在联网后重试。不同 Windows 账号词库请选择独立目录，原文件会保留。

API Key 不随账号同步：Windows 使用当前系统用户加密保存在本机，网页版保存在当前手机的网站本地存储中。调用 AI 时仅发送给你配置的服务商；该服务商需要允许浏览器跨域请求。清除网站数据会清除手机上的本地设置。

06 UPDATE / 保持更新

下一版，在应用里接着用。

点击右上角检查更新，查看版本与更新说明。确认「下载并重启更新」后才会安装；下载过程中可以取消，也可以稍后重试。

有操作尚未完成或输入框里仍有内容时，兔词会保留更新包，等操作完成并保存、清空输入后再重启。更新失败会自动恢复旧文件并提示。

更新包不会清理本地词库、API 设置或额外用户文件。如果使用的是没有更新入口的早期版本，请先从本站下载完整新版本 ZIP，完整解压后打开。

Q&A / 常见问题

你可能还想知道。

没有 API Key，可以先用兔词吗？

可以。导入和阅读已有 Markdown、漫游复习、获取每日阅读，以及查询自带离线词典，都不需要 API Key。只有点击「解析并保存」生成新词卡时，才需要连接自己的接口。

兔词可以离线使用吗？

本地笔记、漫游、自带英汉词典和已缓存的文章正文可以离线使用。获取新文章、调用在线服务商生成词卡需要联网。

词典未命中时，英译中模型在本机运行。模型回退依赖 WebView2，Windows 11 通常已预装；缺少时应用会提示安装。Markdown、漫游、离线词典和纯净正文阅读不依赖浏览器组件。

为什么打开「来源网页」时提示安装 WebView2？

可选的来源网页窗口和离线翻译模型回退使用系统 WebView2 Runtime，发布包没有附带该浏览器运行时。缺少时可从 Microsoft 官方页面（在新标签页打开）安装后重试。日常 Markdown 阅读与漫游不受影响。

必须用 Obsidian 吗？已有笔记会被改写吗？

不需要 Obsidian。兔词可以管理本地词库，也能沿用已有的 Markdown 或 Obsidian 词库。导入会保留源文件，重复收录不会覆盖已有词卡。

词条自动补链只处理程序登记过、且未被人工修改的相关区域；「我的笔记」可以自由补充。自动更新历史笔记前会保留原文备份。

为什么生成失败，或一直在等待？

先检查 API 地址、Key 和模型名是否与服务商提供的信息一致，确认模型支持该接口且账户可用。地址需要包含服务商要求的路径，兔词不会猜测或自动补上 /v1。

生成最长等待 90 秒，可以主动取消。格式校验失败时，界面会提示具体字段；未完成保存时会保留输入，不会用不完整内容覆盖已有笔记。

可以在多台设备间同步学习进度吗？

可以。在 Windows 与手机网页版登录同一账号，可同步词库、复习记录、漫游进度、阅读位置和主题。离线时各端继续保存，联网后合并，同一条复习重试不会重复计数。

API Key 只保留在各自设备，不进入账号同步。换手机、清除网站数据或换到另一个 Windows 用户后，需要重新填写。

更新失败后，原来的词库还在吗？

在应用内更新失败时，更新器会自动恢复旧文件并提示；词库和设置不会被升级包清理。也可以保留原有词库，从下载页获取完整 ZIP，解压到新的文件夹后打开。
